# 00 · 可行性总表

> 结论先行：**六项里 4 项能做、1 项只能做近似、1 项必须 root。**
> 主线（1/2/3/5）不依赖 root，也不需要刷机。

## 评级口径

| 级 | 含义 | 体感 |
|----|------|------|
| A | 可完整复刻 | 用过原版的人会说"就是这个" |
| B | 核心可做，个别环节折损 | "很像，但这里差一点" |
| C | 只能做近似替代 | "名字一样，手感不同" |
| D | 必须 root / 系统签名 | 不 root 免谈 |

## 总表

| # | 功能 | 评级 | 不 root 能做到 | 做不到的那部分 | 工期 |
|---|------|------|---------------|---------------|------|
| 1 | 大爆炸 | **B+** | 长按炸词、词块多选、拖拽合并、搜索/分享 | 任意界面"自然长按"的原生感 | 3–4 周 |

## 1. 大爆炸 BigBang

### 原版拆解
```
长按/双指按压
  → 前摇：屏幕轻微缩放 + 背景虚化
  → 判定：把当前屏幕文字切成「语义块」
  → 表现：文字块飞散成网格，块间留缝
  → 操作：点选多选 / 长按拖动词块合并 / 拖到顶栏搜索·复制·分享
  → 收招：点空白，词块飞回原位
```

### 我们的路线
1. **触发**：边缘长按热区（400ms）+ 通知栏磁贴 + 悬浮球，三选一
2. **取字（混合策略，省 80% 算力）**
   - 先读 `AccessibilityNodeInfo` 树 → 能拿到文字就不 OCR（快、零误差）
   - 拿不到（图片/游戏/Canvas）→ `AccessibilityService.takeScreenshot()` → OCR
3. **OCR**：PaddleOCR(ncnn) 或 RapidOCR，离线、不依赖 GMS
   - 不建议 ML Kit 非 bundled 版：国行魅族没有 GMS
4. **切块**：OCR 的 bounding box → 按行聚类 → 行内按标点切 → jieba 词级细分
5. **悬浮层**：`TYPE_ACCESSIBILITY_OVERLAY`（无障碍服务自带的窗口类型，不用额外悬浮窗权限，系统不会裁）
6. **拖拽**：层内普通拖拽；出层用 `startDragAndDrop` + `ClipData`

### 卡点
- Flyme 是否允许无障碍截图（**必须在第 0 期验证**）
- OCR 单帧 300–800ms（骁龙 8 Gen 3 可接受，可以做"先出框、后填字"）
- 悬浮层与手势导航/输入法抢触摸
- 无障碍被系统杀

### 参考
- `SmartisanTech/packages_apps_BigBang`（官方，Apache-2.0）→ **算法与交互逻辑可读可抄**
- `baoyongzhang/BigBang`（第三方，MIT，2018 停更）→ 可跑的完整实现，当骨架参考

## 2. 一步 OneStep

### 原版拆解
```
屏幕角向内划
  → 侧栏滑出：顶部最近联系人/应用 · 中部应用列表 · 底部最近文件图片
  → 核心动作：从当前 app 长按内容 → 拖进侧栏（收藏/发送）
              从侧栏长按内容 → 拖进当前 app（插入/发送）
  → 收招：划回 / 点空白
```

### 我们的路线
| 能力 | 能否做 | 做法 |
|------|--------|------|
| 侧栏外观 | 100% | 悬浮窗 + 边缘热区 |
| 侧栏里放应用/联系人/文件 | 100% | `QUERY_ALL_PACKAGES` / `READ_CONTACTS` / `READ_MEDIA_*` |
| 从侧栏拖内容到当前 app | 80% | `Intent` 分享 或 `startDragAndDrop` |
| 从当前 app 拖内容进侧栏 | **30%** | 跨应用拖拽必须源 app 主动发起，第三方无法劫持 |
| 分屏快捷 | 100% | 侧栏点应用 = 分屏/浮窗 |

**"拖出来"的替代方案（按体验排序）**
1. 系统分享菜单加一个「存到一步」（`ACTION_SEND` + `ACTION_PROCESS_TEXT`）——稳，但多两步
2. 无障碍模拟长按选中 + 复制——不稳定，不同 app 表现不同
3. 剪贴板监听——用户先复制，侧栏自动收

### 结论
**一步是六项里性价比最低的。** 投入大、折损大。
建议先做最小闭环：**侧栏 + 分享收件箱 + 剪贴板历史 + 分屏**，不做"任意界面随手拖"。

### 参考
- `SmartisanTech/packages_apps_OneStep`（官方，许可证 NOASSERTION）→ **只能读逻辑，不能搬代码**，用前先看仓库 LICENSE

## 3. 闪念胶囊 Idea Pills

### 原版拆解
```
长按快捷键
  → 底部升起胶囊，背景压暗
  → 按住说话：实时波形 + 实时转文字（松手也可转）
  → 松手：胶囊缩小落底，成为一条记录
  → 胶囊列表：时间轴排列，可转待办/日程/分享/删除
```

### 我们的路线
- 触发：悬浮球 / 长按音量下 / 磁贴 / 快捷方式（耳机线控会和音乐抢 `MediaSession`，后置）
- 录音：`AudioRecord` + 波形（Compose Canvas）
- 转写：
  - 默认离线 **sherpa-onnx**（Zipformer 中文，约 80MB，实时）
  - 可选在线（系统 `SpeechRecognizer`）
- 存储：Room（胶囊表 + 音频文件路径）
- 列表：时间轴分组，拟物卡片

### 卡点
- Android 14 前台服务必须声明 `microphone` 类型
- 后台录音被省电策略掐（需要白名单引导）
- 离线模型体积（首次启动下载或随包 80MB）

**这是第一个该做的东西。** 每天都能用，正反馈最快，还能顺带把"触发层 + 拟物设计系统"两块地基打出来。

## 4. 无限屏 Infinite Screen

### 原版拆解
```
底部上滑并按住
  → 当前界面缩小，进入全景空间
  → 所有 app 以卡片悬浮在 3D 空间
  → 移动手机（陀螺仪）→ 视角平移，像透过窗口看更大的世界
  → 松手：选中项放大进入
```
本质是**用陀螺仪代替滑动的空间导航**。

### 我们的路线
- 做不了系统 Recents 替换（那需要系统签名）
- 能做两件事：
  1. **自己的桌面（Launcher）**：接管 `HOME`，桌面本身就是无限屏
  2. **全局应用墙**：手势唤起，卡片墙 + 陀螺仪视差（只是启动器，不是任务切换器）
- 陀螺仪：`TYPE_GAME_ROTATION_VECTOR`
- 3D：Compose `graphicsLayer` + `rotationX/Y` + `cameraDistance`，不用 OpenGL

### 卡点
- 换桌面会影响 Flyme 手势导航 / 负一屏 / 小窗
- 必须做成"可选桌面"，不强制

## 6. 系统级拟物

### 不 root 的天花板
能：桌面、图标包、字体、铃声、壁纸
不能：状态栏、通知栏、设置、拨号、短信、音量条、锁屏

### root 路线（可选支线）
- Magisk / KernelSU + RRO overlay 改 SystemUI 资源
- LSPosed 模块改布局
- **代价**：魅族 21 Pro 解锁走 meizubl 体系（第三方付费工具），**清空数据**；root 后银行/支付类 App 可能拒跑
- 魅族已退出手机业务，系统不再 OTA，解锁后不会因为更新回锁——这是唯一的好消息

**评级 D。放最后。不做也不影响前五项。**

## 附：锤子味道清单（设计系统种子）

不是"复古 UI"，是这六件事：

1. **材质有重量**：拉丝金属、皮革、纸、木纹、玻璃——每个面板都能说出"它是什么做的"
2. **光只有一个方向**：左上 45°。高光、内阴影、外投影全部服从同一个光源
3. **圆角是倒角不是胶囊**：物理切角（chamfer），不是现代的大圆角
4. **动效有机械感**：卡扣、翻页、齿轮、弹簧——不是 ease-in-out 的"果冻"
5. **声音是拟物的**：咔哒、翻页、快门、按键回弹
6. **信息密度高**：一屏能放很多，但不乱；用分割线和凹槽分区，不用大留白
