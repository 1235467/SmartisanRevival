# 09 · 参考库清单

> 核心发现：**Smartisan 官方把 BigBang 和 OneStep 的源码开源了。**
> 大爆炸的核心算法可以直接读官方实现；一步只能读逻辑（许可证不明）。

---

## 一、官方开源（github.com/SmartisanTech）

| 仓库 | 星 | 语言 | 许可证 | 对我们 |
|------|----|------|--------|--------|
| `packages_apps_BigBang` | 263 | Java | **Apache-2.0** | ★★★ 官方大爆炸实现，**算法可读可抄** |
| `packages_apps_OneStep` | 472 | Java | **NOASSERTION** | ★★ 官方一步实现，**只读逻辑，不搬代码** |
| `SmartisanOS-SDK` | 114 | Java | Apache-2.0 | ✕ 给第三方 App 调 Smartisan ROM 的，我们的手机不是 Smartisan ROM，无用 |
| `android` | 2721 | — | Apache-2.0 | ★ 全系统 repo manifest，想找某个系统 App 的源码时当索引 |
| `android_frameworks_smartisanos-base` | 15 | Java | Apache-2.0 | ★ 理解 Smartisan 私有 Framework 改了什么 |
| `SmartisanOS_Kernel_Source` | 461 | C | GPL-2.0 | ✕ 内核，无关 |

**怎么用**：`packages_apps_BigBang` 是 AOSP 里的系统 App，依赖 Smartisan 私有 API，**不能直接编译到魅族上**。
但它把"怎么切块、怎么算 bounding box、怎么处理多选"写得很清楚，可以照着用 Kotlin 重写。

## 二、第三方复刻

| 仓库 | 星 | 语言 | 许可证 | 最后更新 | 对我们 |
|------|----|------|--------|---------|--------|
| `baoyongzhang/BigBang` | 988 | Java/Lex | **MIT** | 2018-08 | ★★★ 能跑的大爆炸复刻，当骨架参考（无障碍 + 截图 + OCR 的完整链路） |
| `fantasyao/shengwuji`（声物记） | 134 | Dart | **Apache-2.0** | 2026-10 | ★★★ **闪念胶囊复刻 + 离线语音识别**，直接对标我们的第 1 期 |
| `rianlu/smartisan-launcher-maintained` | 756 | Smali | 无 | 2026-08 | ★★ 锤子桌面非官方维护版（反编译改的），行为/交互参考，代码不可用 |
| `People-11/SmartisanOS_APP_Port` | 228 | — | 无 | 2026-07 | ★★ 原版 App 移植 wiki，查"哪个能装、哪个崩" |

**特别注意 `shengwuji`**：它做的就是我们第 1 期要做的事（复刻闪念胶囊 + 离线语音），
而且是 Apache-2.0、今年还在更新。**第 1 期开工前必须先读它**，能省掉大量试错。

## 三、许可证红线

| 档 | 许可证 | 能做什么 |
|----|--------|---------|
| **绿** | Apache-2.0 / MIT | 可以复制代码、修改、分发。保留 LICENSE 和 NOTICE 即可 |
| **黄** | NOASSERTION（GitHub 没识别出来） | **先去仓库里看 `LICENSE` 文件**。没有文件 = 默认保留所有权利 = 只能读 |
| **红** | 无许可证 / 只有二进制 | 只能读思路和行为，**一行代码都不能复制** |

`packages_apps_OneStep` 是黄档，`smartisan-launcher-maintained` 和 `SmartisanOS_APP_Port` 是红档。

项目如果开源，最终要有一份 `THIRD_PARTY_NOTICES.md` 记录引用来源。

## 四、要用的第三方库

| 用途 | 库 | 许可证 | 备注 |
|------|----|--------|------|
| OCR | RapidOCR / PaddleOCR-ncnn | Apache-2.0 | 离线、中文准、不依赖 GMS |
| 分词 | jieba-android | MIT | — |
| 离线语音 | sherpa-onnx | Apache-2.0 | Zipformer 中文模型约 80MB |
| 数据库 | Room | Apache-2.0 | — |
| 图片 | Coil | Apache-2.0 | — |
| UI | Compose BOM | Apache-2.0 | — |
| 权限引导 | 自己写 | — | 各 ROM 差异太大，现成库都不准 |

**不要用**：ML Kit 非 bundled 版（国行魅族无 GMS）。

## 五、每个功能看哪个库

| 功能 | 首读 | 次读 |
|------|------|------|
| 大爆炸 | `SmartisanTech/packages_apps_BigBang`（官方算法） | `baoyongzhang/BigBang`（可跑实现） |
| 一步 | `SmartisanTech/packages_apps_OneStep`（只读） | — |
| 闪念胶囊 | `fantasyao/shengwuji`（同类竞品，Apache-2.0） | — |
| 无限屏 | `rianlu/smartisan-launcher-maintained`（桌面行为） | — |
| 拟物 App | `People-11/SmartisanOS_APP_Port`（哪些能装） | 官方仓库里的系统 App 源码（找不到就复刻） |
| 系统级拟物 | 无开源参考，只能自己做 RRO overlay | — |
